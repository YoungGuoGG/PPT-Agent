# Layout and Style

- Use one dominant visual hierarchy per page.
- Vary anchor, dense, and breathing pages across the deck.
- Avoid repeating a card grid on every page.
- Keep titles short, body text readable, and evidence close to the claim it supports.
- Use comparison, timeline, process, matrix, chart, or scene layouts only when the content relationship warrants them.
- Treat brand tokens as constraints, not decoration suggestions.
- Prefer a small, coherent palette and a stable spacing scale.
- Retrieve a few compatible style cases and borrow visual grammar, not text, logos, or customer data.
