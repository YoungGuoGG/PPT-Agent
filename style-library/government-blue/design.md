# 政务蓝

## Positioning

庄重、明确、有秩序。突出政策结构、工作成效和行动安排，避免过度装饰。

## Color Tokens

- `background`: `#F5F8FC`
- `surface`: `#FFFFFF`
- `text`: `#15253D`
- `muted`: `#5E6C80`
- `accent`: `#145DA0`
- `secondary`: `#2E8BC0`
- `highlight`: `#B88A2B`

## Typography

- 中文统一使用 Microsoft YaHei，数字与英文使用 Arial。
- 标题层级端正稳定，正文 18–22 px；正式文件名称可加粗，不使用花体字。
- 一页不超过三个字重层级。

## Page Rhythm

背景与目标 → 总体部署 → 分项举措 → 成效数据 → 问题与下一步。章节页明确切换阶段。

## Layout Grammar

- 使用对称或稳定栅格，标题区、内容区和页脚区边界清楚。
- 流程按自上而下或从左到右排列，不交叉回绕。
- 重点数字可放大，但必须附带口径和时间范围。

## Charts

使用蓝色主系列与金色重点；减少三维效果；指标必须注明单位、口径和来源。

## Image and Icon Policy

优先使用授权的现场照片、地图、业务示意和统一线性图标。机构标识只在用户提供并授权时使用。

## Do Not

- 不使用未经授权的徽标和机构名称。
- 不用娱乐化贴纸或夸张动效。
- 不省略数据口径、来源和时间。
- 不使用高饱和多色渐变。
