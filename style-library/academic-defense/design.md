# 学术答辩

## Positioning

严谨但不沉闷，以研究逻辑和实验可信度为第一目标，视觉重点放在方法关系与结果差异。

## Color Tokens

- `background`: `#F8FAFC`
- `surface`: `#FFFFFF`
- `text`: `#14213D`
- `muted`: `#5B677A`
- `accent`: `#176B87`
- `secondary`: `#64CCC5`
- `highlight`: `#E9C46A`

## Typography

- 中文使用 Microsoft YaHei，公式与英文使用 Arial 或 Cambria。
- 页标题 30–36 px，正文 18–21 px，图表标注不小于 14 px。
- 方法名、指标名、数据集名保持原始拼写并使用稳定字重。

## Page Rhythm

问题定义 → 研究缺口 → 方法总览 → 模块细节 → 实验设置 → 结果与消融 → 局限与结论。每两到三页安排一页结构或证据主导页面。

## Layout Grammar

- 方法图使用从左到右的单一主流向，子模块按阶段分组。
- 实验页优先“结论句 + 图表 + 解释”，避免把论文表格直接截图。
- 页脚可显示章节与页码，但不得抢占视觉焦点。

## Charts

同一指标跨页使用同一颜色映射；基线用中性灰，本文方法用强调色；必须标明指标方向和单位。

## Image and Icon Policy

优先使用结构图、实验可视化与必要示意图。照片只用于任务背景，图标仅辅助区分模块。

## Do Not

- 不编造论文结论、数据或引用。
- 不省略实验条件和指标方向。
- 不把复杂架构图压缩到不可读。
- 不用装饰性图片代替方法解释。
