# 暖色编辑

## Positioning

有温度、重叙事、像经过编辑的专题文章。通过大标题、图片和节奏变化引导阅读。

## Color Tokens

- `background`: `#F6F0E6`
- `surface`: `#FFFDF8`
- `text`: `#2B2520`
- `muted`: `#76695D`
- `accent`: `#C65D3B`
- `secondary`: `#2F6F68`
- `highlight`: `#D9B44A`

## Typography

- 中文使用 Microsoft YaHei；英文标题可使用 Georgia，正文使用 Arial。
- 允许大字号标题与小型眉题形成编辑层级；正文保持舒适行长和行距。
- 引语只用于真正有来源的关键话语。

## Page Rhythm

大图或大标题开场；在叙事页、数据页、人物/案例页之间切换；段落结束使用一句有力度的结论。

## Layout Grammar

- 使用非对称网格，但保持清晰对齐线。
- 图片可占据半页以上，文字区域不压在复杂背景上。
- 色块用于章节和引用，不把所有内容卡片化。

## Charts

优先简单比较、时间线与少量数据；使用暖色强调结论，图表背景保持纸张感和低噪声。

## Image and Icon Policy

图片质量优先，裁切应保留人物视线与主体空间。图标尽量少用，必要时使用简洁轮廓风格。

## Do Not

- 不使用无来源的伪造引语。
- 不把多段长文并排塞进一页。
- 不混用多种照片色调。
- 不用大量卡片破坏叙事连续性。
